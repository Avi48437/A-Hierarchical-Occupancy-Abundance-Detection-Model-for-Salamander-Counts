# Hierarchical Occupancy–Abundance–Detection Model for Salamander Counts

Code for salamander count data using zero-inflated and hierarchical occupancy–abundance–detection models.

**Structure:** Codes/ → data_prep.R, exploratory_plots.R, zinb_comparison.R, hierarchical_model.R, dharma_diagnostics.R  
**Run order:** data_prep → exploratory_plots → zinb_comparison → hierarchical_model → dharma_diagnostics  
**Packages:** glmmTMB, DHARMa, ggplot2, dplyr
